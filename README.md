## AIM
To evaluate and compare the effectiveness of prompting techniques (zero-shot, few-shot, chain-of-thought, role-based) across different AI platforms (e.g., ChatGPT, Gemini, Claude, Copilot) in a specific task: text summarization.

## Scenario:
You are part of a content curation team for an educational platform that delivers quick summaries of research papers to undergraduate students. Your task is to summarize a 500-word technical article on "The Basics of Blockchain Technology" using multiple AI platforms and prompting strategies.

Your goal is to determine which combination of prompting technique + platform provides the best summary in terms of:

Accuracy

Coherence

Simplicity

Speed

User experience

# AI Tools Used:
* ChatGPT
* Gemini

## Algorithm
Step 1: Select a specific application, such as AI-based student performance prediction.

Step 2: Choose AI platforms such as ChatGPT and Gemini.

Step 3: Prepare five different prompt structures:
- Basic Prompt
- Role Prompt
- Context Prompt
- Constraint Prompt
- Output Format Prompt
Step 4: Enter the same prompts into both AI platforms.

Step 5: Generate responses for each prompting technique.

Step 6: Collect and save the generated outputs from both platforms.

Step 7: Evaluate the responses based on accuracy, coherence, simplicity, speed, and user experience.

Step 8: Compare the responses generated by ChatGPT and Gemini.

Step 9: Identify the most effective prompting technique and AI platform.

Step 10: Document the observations, comparison, and final results.

# EXPERIMENT:
## Designing Different Prompt Structures for AI-Based Student Performance Prediction
## Selected Application:
## AI and Blockchain-Based Student Performance Prediction System
1. Basic Prompt
Explain how Artificial Intelligence and Blockchain technology can be used together to predict student academic performance using attendance, assignment scores, study hours, and previous examination marks.
2. Role Prompt
Act as an AI, Machine Learning, and Blockchain professor. Explain how an AI-based student performance prediction system works with Blockchain technology. Include simple examples of how Blockchain securely stores student academic records.
3. Context Prompt
A college wants to develop an AI and Blockchain-based student performance prediction system. Explain how Machine Learning predicts student performance using attendance, assignment scores, study hours, and previous examination marks, while Blockchain ensures the security, transparency, and integrity of academic records.
4. Constraint Prompt
Explain an AI and Blockchain-based student performance prediction system in exactly 100 words using simple English. Include the four input factors, the role of AI in prediction, the role of Blockchain in data security, and two benefits.
5. Output Format Prompt
Explain an AI and Blockchain-based student performance prediction system using simple English. Organize the answer under four headings: Introduction, Input Factors, Working Process, and Benefits. Present the working process in numbered steps and benefits in bullet points. Include how AI predicts performance and Blockchain securely stores academic records.
